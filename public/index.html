What is traveling? Binary LFTP frames over TCP between laptops. The browser upload is a local handoff to the sender helper, not the protocol link. Packet animation is illustrative, not a timing or speed measurement.
01 · OFFERSender declares safe filename, size, digest and transfer ID.
02 · READYReceiver says the next byte it still needs. On retry, this can be a saved offset.
03 · DATA / ACKOne 256 KiB-or-smaller chunk at a time. ACK follows file sync and checkpoint update.
04 · FINISH / COMPLETEReceiver checks SHA-256, publishes without overwrite, and confirms completion.
